## ADDED Requirements

### Requirement: 应用外壳与导航

系统 SHALL 采用 Windows 桌面外壳：40px 标题栏（应用名 + 右侧最小化/最大化/关闭）、232px 左侧栏、右侧主区。侧栏 MUST 包含「仪表盘 / 节点 / 连接」与底部的「设置 / 日志」，并标出当前页。M1 不使用 macOS 交通灯。

#### Scenario: 启动后进入仪表盘

- **WHEN** 应用启动并完成内核握手
- **THEN** 默认停在「仪表盘」，侧栏该项处于选中态，标题栏显示应用名与 Windows 窗控

#### Scenario: 从侧栏进入连接页

- **WHEN** 用户点击侧栏的「连接」
- **THEN** 主区切换为连接列表，侧栏选中态同步，返回「仪表盘」只需一次点击

### Requirement: 仪表盘主视图

系统 SHALL 以卡片仪表盘作为默认页，至少包含四块：当前节点（节点名、策略组、健康度、60 分钟刻度条）、内核状态（版本、端口、策略组数、启动时间、内存）、三张速率卡（下载、上传、活跃连接）、流量历史折线图。

#### Scenario: 首屏完整可见

- **WHEN** 窗口为 1280×800 时打开仪表盘
- **THEN** 四块内容全部可见，折线图不被裁切，无需滚动

#### Scenario: 窄窗口重排

- **WHEN** 窗口宽度降到 1100px 以下
- **THEN** 三列网格折叠为两列、再折叠为一列，卡片内容不被裁切或横向滚动

### Requirement: 模式切换

系统 SHALL 在顶栏常驻提供「规则 / 全局 / 直连」三模式切换，当前模式有明确的选中态。切换 MUST 实际改变内核的 `mode`（`PATCH /configs`），并立即反映到状态显示。

#### Scenario: 切换到全局模式

- **WHEN** 用户点击「全局」
- **THEN** 应用调用 `PATCH /configs {"mode":"global"}`，成功后选中态移到「全局」，失败时回滚选中态并提示错误

#### Scenario: 模式与连接页一致

- **WHEN** 用户切到「直连」后打开连接页
- **THEN** 新产生的连接在出站列显示 `DIRECT`，与模式一致

### Requirement: 令牌与形状约束

系统 SHALL 使用 `tokens/` 中定义的颜色、字号、圆角与间距。组件代码中 MUST NOT 出现裸色值、裸 px 或裸字号，由 lint 规则强制。

#### Scenario: 违反令牌

- **WHEN** 组件样式里出现十六进制色值或硬编码圆角
- **THEN** lint 失败并阻止提交

### Requirement: 键盘可达

系统 MUST 保证六个核心任务可仅用键盘完成：切换节点、开关系统代理、切换模式、进入连接页、展开某条连接详情、退出。

#### Scenario: 全键盘操作

- **WHEN** 用户全程不使用鼠标
- **THEN** 通过 `Ctrl K`、方向键、`Enter`、`Esc` 可以完成上述六个任务

### Requirement: 命令面板

系统 SHALL 提供命令面板，包含节点搜索与六个全局动作：开关代理、切换模式、重启内核、打开配置目录、查看日志、复制当前节点名。

#### Scenario: 通过命令面板切换节点

- **WHEN** 用户在命令面板中输入节点名并回车
- **THEN** 当前节点被切换，仪表盘的当前节点卡与侧栏节点页同步更新

### Requirement: 空状态

系统 SHALL 提供三种空状态，每种带明确的主操作：无配置、已配置但无流量、内核失败。空状态不得阻断侧栏导航。

#### Scenario: 首次启动无配置

- **WHEN** 配置目录为空
- **THEN** 仪表盘显示「还没有配置」的引导卡与导入入口，不自动启动内核

#### Scenario: 内核失败

- **WHEN** 内核处于错误状态
- **THEN** 仪表盘显示错误摘要与「查看日志 / 重启内核」两个动作，侧栏仍可操作

### Requirement: 托盘菜单

系统 SHALL 提供托盘菜单，包含只读状态行（当前节点与模式）、系统代理开关、切换节点子菜单、打开主窗口、退出。

#### Scenario: 通过托盘切换

- **WHEN** 用户从托盘菜单的节点子菜单中选择一个节点
- **THEN** 节点切换生效，仪表盘（若已打开）同步更新

#### Scenario: 托盘不刷新速率

- **WHEN** 流量速率每秒变化
- **THEN** 托盘菜单不重建，速率只在仪表盘显示
