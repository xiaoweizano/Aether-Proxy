## ADDED Requirements

### Requirement: 开机自启

系统 SHALL 提供开机自启能力，并默认启用。用户关闭自启时，MUST 显示「重启后若系统代理仍处于开启状态，需要手动启动 Aether」的警告。

#### Scenario: 默认自启

- **WHEN** 用户安装并首次运行后重启计算机
- **THEN** Aether 自动启动到托盘，系统代理指向可用端口

#### Scenario: 用户关闭自启

- **WHEN** 用户在设置中关闭开机自启
- **THEN** 界面显示上述警告，且不再注册自启项

### Requirement: 启动顺序

系统 MUST 按固定顺序完成启动：检测并还原残留代理 → 读取配置 → 启动内核并握手 → 若上次代理为开启状态则重新应用。任一前置步骤失败时 MUST NOT 应用系统代理。

#### Scenario: 上次异常退出

- **WHEN** 应用启动并发现上次留下的代理标记
- **THEN** 先还原系统代理，再按正常流程启动，并提示已恢复

#### Scenario: 配置损坏

- **WHEN** 启动时 `runtime.yaml` 无法通过校验
- **THEN** 不应用系统代理，进入错误状态并提供重新导入配置的入口

### Requirement: 退出顺序

系统 MUST 先还原系统代理，再终止 mihomo 子进程，最后退出应用。顺序不得颠倒。

#### Scenario: 从托盘退出

- **WHEN** 用户选择退出
- **THEN** 系统代理先被还原，随后内核进程被终止并确认，应用退出

### Requirement: 窗口隐藏即销毁

系统 SHALL 在主窗口关闭时销毁窗口对象而非隐藏，仅保留托盘与主进程。重新打开时重建窗口并恢复状态。

#### Scenario: 关闭主窗口

- **WHEN** 用户点击窗口关闭按钮
- **THEN** 窗口被销毁，托盘图标仍在，代理与内核继续运行

#### Scenario: 常驻资源目标

- **WHEN** 窗口已销毁且无额外窗口存在，应用已运行 5 分钟
- **THEN** `Aether.exe` 全部进程与 `mihomo.exe` 的 Working Set 之和低于 150 MB

### Requirement: 未实现单实例锁

M1 MUST NOT 声明单实例保证。若检测到已有实例在运行，系统 SHOULD 提示用户，但不需要阻止第二个实例启动。

#### Scenario: 重复启动

- **WHEN** 用户在 Aether 已运行时再次启动
- **THEN** 显示提示，说明同一用户下可能存在多个实例与多个内核
